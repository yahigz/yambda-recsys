# Музыкальные рекомендации на Yambda

**Студент:** Останин Андрей Михайлович

**Датасет:** [Yambda](https://huggingface.co/datasets/yandex/yambda) — логи Яндекс Музыки (прослушивания, лайки, дизлайки, привязка треков к артистам и альбомам), Apache 2.0, [arXiv:2505.22238](https://arxiv.org/abs/2505.22238). Используется воспроизводимая подвыборка версии `flat/50m`: последние 60 дней лога, 25% пользователей (seed 42), итеративное k-core. После очистки — 2165 пользователей, 13 149 треков, 737 тыс. пар, 1,77 млн прослушиваний.

Сравниваются пять моделей, реализованных с нуля (`models/`), на задаче персональных top-10 рекомендаций **новых** треков. Разбиение глобальное по времени: train — 47 дней, val и test — по неделе. Релевантен трек, дослушанный больше чем на 50% или лайкнутый и не дизлайкнутый. Главная метрика — NDCG@10, дополнительные — Recall@10, Coverage@10 и средняя популярность рекомендаций.

## Результаты на test

| Модель | NDCG@10 | Recall@10 | Coverage@10 |
|---|---|---|---|
| Popular (бейзлайн) | 0.0374 | 0.0389 | 0.005 |
| ItemKNN | 0.0609 | 0.0630 | 0.208 |
| FM с метапризнаками | 0.0660 | 0.0667 | 0.249 |
| iALS | 0.0699 | 0.0708 | 0.228 |
| EASE | 0.0741 | 0.0733 | 0.202 |
| **iALS со своим целевым сигналом** | **0.0832** | **0.0832** | 0.197 |

Параметры, подбор и выводы — в `experiments.ipynb`.

## Структура

| Путь | Что это |
|---|---|
| `prepare_data.ipynb` | Загрузка Yambda с Hugging Face и построение подвыборки |
| `experiments.ipynb` | Основной ноутбук: данные, EDA, протокол, подбор моделей, сравнение, выводы |
| `models/common.py` | Загрузка, агрегаты по парам, временное разбиение, матрицы, top-k |
| `models/metrics.py` | NDCG@10, Recall@10, Coverage@10, популярность рекомендаций |
| `models/tuning.py` | Подбор Optuna (TPE) на val и финальная оценка на test |
| `models/popular.py` | Бейзлайн Popular |
| `models/itemknn.py` | Item-based CF: косинусная близость со shrinkage, top-k соседей |
| `models/ease.py` | EASE (Steck, 2019), решение в замкнутой форме |
| `models/ials.py` | iALS (Hu, Koren, Volinsky, 2008), точные шаги ALS |
| `models/ials_custom.py` | iALS со своим целевым сигналом: доля дослушиваний и лайков, затухающая с давностью |
| `models/fm.py` | Факторизационная машина с метапризнаками, обучение BPR (PyTorch) |

## Запуск

1. `prepare_data.ipynb` скачивает Yambda с Hugging Face и строит подвыборку в `data/yambda_subsample/`.
   На Kaggle (CPU, Internet On) подвыборка окажется в output ноутбука. Данные в репозиторий не входят.
2. `pip install -r requirements.txt` (Python 3.12), положить `yambda_subsample/` в `data/` и запустить
   `experiments.ipynb` целиком из корня репозитория. На CPU (Mac M-серии) полный прогон занимает около 4 часов,
   из них около 3 часов уходит на подбор FM. Таблицы подбора сохраняются в `outputs/`.

Seed и параметры экспериментов заданы в первой ячейке каждого ноутбука.
Обучение FM в PyTorch не полностью детерминировано: повторные запуски расходятся в NDCG@10 примерно на 0,003.
